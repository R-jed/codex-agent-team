# Evaluation artifacts

- `behavioral-workloads.json`: experiment shapes, not benchmark results.
- `behavioral-result.schema.json`: machine-checkable live result format.
- `LOCAL_EVAL_FIXTURE_TEMPLATE.md`: freeze an executable local workload before paired live runs.
- `routing-cases.json`: static orchestration policy cases.
- `runtime-assurance-cases.json`: static Runtime Truth reconciliation cases.

See [`../docs/behavioral-evals.md`](../docs/behavioral-evals.md) for the live paired-run protocol and [`../HEADOFF.md`](../HEADOFF.md) for the local validation sequence.
